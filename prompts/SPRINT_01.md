# 首轮可执行开发任务：网页采集器校准与 NAS 首次验收

你接手了 V0.2 工程，请在不破坏现有表和 API 的前提下完成以下内容：

1. 收集并整理**来源明确、允许开发使用**的贝壳和安居客宁波二手房页面HTML样本，每平台至少20份，至少涵盖详情页、无效/下架页面、价格变化、布局变化、字段缺失情况。样本若暂不可获得，则先添加对应fixture结构和抽取失败测试，明确未验证。
2. 以 `app/collectors/parser.py` 为基础拆分 `beike.py`、`anjuke.py` 专用解析器；记录字段提取证据片段与 `parser_version`，保证多价/多面积不猜测。
3. 校验页面 URL 的来源ID稳定性；非详情页不得生成虚构ID。网页抓取在线权限继续按来源状态开关，默认禁用；403/429/robots禁止时阻断。
4. 使用已有 `collection_candidates` 逐条进入人工审核；拒绝和修正记录须可追溯；正式价格历史只接收确认后的挂牌数据。
5. 完成 `docs/NAS_DEPLOYMENT.md` 的V0.2迁移和测试流程，若无NAS连接，提供可直接复制执行的验收命令并标注未验证。
6. 新增可跑的单元测试和必要的集成测试，目标为字段完整率、解析准确率分别可计算，不能仅报告抓到多少条。

验收：单测通过、源码可编译、迁移可重复运行、历史价格不被倒灌覆盖、误判复核池可查看、平台站点采集未获得权限时确实不发起网页请求。

提交最终变更文件、测试记录和下一轮P0待办，更新 `docs/PROJECT_STATUS.md` 与 `CHANGELOG.md`。
