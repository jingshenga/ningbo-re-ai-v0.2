## 各来源当前能力拆解
- **可运行的离线采集候选流程**：手工保存/合法取得HTML → `/api/collection/pages` → 通用解析器 → `collection_candidates` → 人工复核 → `source_listings` → `price_history`。
- **Worker列表分页准备**：列表目标通过来源许可和全局开关后，每轮最多处理5页/20个详情页，游标落在`collection_discovery_states`；详情抓取失败可回退；robots/upstream阻断会暂停目标并停止自动重试。当前只用mock验证，无真实许可页面、PG端到端或NAS验收；在线保持关闭。
- **代码中存在的在线适配器**：仅支持经审核允许且robots批准的HTTPS目标页面；默认 `ENABLE_ONLINE_COLLECTION=false` 且 `source_registry.online_enabled=false`。真实平台页面布局及抓取有效率未验证；2026-11-12经NAS按代码UA直连复核实际目标主机robots，贝壳示例详情路径拒绝、安居客示例路径允许；结果、哈希和适用范围见`SOURCE_POLICY_REVIEW_2026-11-12.md`。
- **未来授权API**：保留 `current_mode=licensed_api` 和统一来源ID；目前没有实现贝壳/安居客的授权接口。
- **替代路线**：允许许可的公开数据、政府公开资料、合作中介主动提交、用户主动提供的房源链接/截图（注意权属及使用范围）。
