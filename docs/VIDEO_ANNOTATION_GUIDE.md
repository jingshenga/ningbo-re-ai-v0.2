# 真实房产视频识别验收：最小人工标注规范

目标：为 ≥10 段**确认有权处理**的真实房产介绍视频建立可复核标注与统一统计口径。素材未取得前只交付本规范与工具，不虚构准确率；不自动抓取抖音/视频号。

## 1. 素材准入

- 每段视频须附：来源（自摄/获作者授权/获平台授权）、授权说明、采集日期。无法确认权利的视频不得进入测试集。
- 建议覆盖：横屏与竖屏、清晰与模糊（转发压缩）、字幕式（大字）与口播式、多价格画面（原价/现价/广告价）至少各 2 段。

## 2. 标注表（CSV：`docs/VIDEO_ANNOTATION_TEMPLATE.csv`）

每段视频一行，字段如下（UTF-8，逗号分隔；未出现填空，未知填 `unknown`）：

| 列 | 说明 | 示例 |
|---|---|---|
| video_id | 视频文件名（不含扩展名） | `listing_07` |
| source_note | 来源与授权说明 | `自摄 2026-11-12` |
| orientation | `horizontal` / `vertical` | `vertical` |
| community_truth | 人工核实的小区名 | `东湖花园` |
| area_truth_sqm | 建筑面积数字 | `160` |
| bedroom_truth | 室数（阿拉伯数字） | `4` |
| price_truth_wan | **当前报价**（若画面同时有历史价，只标当前价） | `365` |
| other_prices_truth | 其余价格及类型，分号分隔 | `380:历史价;355:成交价;100:首付` |
| floor_truth | 楼层文字（若有） | `中层/18层` |
| on_screen_text_truth | 画面出现的完整文字行，竖线分隔 | `东湖花园 急售\|报价365万\|建面160㎡` |
| oral_price_truth | 口播报价（若有逐字稿） | `365` |
| notes | 人工备注（遮挡/水印/多套房源混排等） | `第2秒起有水印遮住面积` |

## 3. OCR 原文与错误位置记录

复测工具自动输出（无需人工填）：每帧识别文本、帧号、时间戳、置信度；人工复核时在 `notes` 中标注错误位置（如"面积行的㎡识别成m"）。统计口径与合成试点一致：

- 行级命中 = 去空格 + 单位等价（`㎡`≡`m²`≡`平米`）；
- 字段级 = `hints` 候选集合与 truth 集合相等（价格/面积/户型/小区分别统计正确率与缺失率）；
- 价格类型区分 = `other_prices_truth` 中每类价格都应出现在 `price_mentions_wan` 线索且**不得**写入 `source_listings`/`price_history`。

## 4. 执行步骤（零代码改动）

1. 将视频与标注 CSV 放入同一目录（文件名与 `video_id` 对应）；
2. 运行 `python scripts/quality_pilot_run.py --csv <标注CSV> --dir <视频目录> --known-communities <小区名单>`（真实 RapidOCR，逐视频输出 `*.result.json` 与 `/usr/bin/time` 资源数据）；
3. 运行 `python scripts/quality_pilot_report.py --csv <标注CSV> --dir <视频目录>` 生成对比表（truth vs OCR vs hints + 耗时/内存）。

## 5. 验收通过标准（建议，可由产品调整）

- 小区/价格/户型字段正确率 ≥80%（10 段规模下单字段允许 ≤2 段失败）；
- 每类价格（画面/口播/历史/广告）100% 仅作线索，`source_listings`/`price_history` 零写入；
- 单视频（≤60s）端到端耗时与峰值内存不超过合成基线的 1.5 倍（横屏 ~482MB/1s、竖屏 ~479MB/0.6s 为基准）；
- 所有失败场景有人工复核记录，漏/误识别规律汇总进本规范附录。
