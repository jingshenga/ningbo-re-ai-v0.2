## 当前及计划用途

当前仅计划在获得书面许可后，对宁波二手房挂牌信息进行有限采集或导入、人工审核、来源内价格历史记录和内部条件单测试。未经审核的页面解析结果不会直接发布为正式挂牌或成交信息。

产品后续规划包括向购房者提供免费找房和提醒；中介联系或撮合仅在用户明确授权后进行。当前没有公开发布或商业化服务。请分别确认上述当前用途、未来免费展示/提醒，以及未来经用户授权的中介撮合是否允许；任何需要另行签约、审批或付费的用途均可单独列明。项目不申请转售原始数据或向无关第三方提供数据。

## 拟申请的数据范围

如平台允许，请确认可提供或处理的字段：

- 来源挂牌 ID、来源页面链接、所在区域/小区；
- 挂牌价格、建筑面积、户型、在售/下架状态及其更新时间；
- 用于核对来源和变更的必要证据字段。

默认不采集或保存经纪人/业主姓名、电话、头像、私信、评论及其他非必要个人信息，不申请使用房屋照片、视频或其他媒体素材。若必要字段不同，请平台指出允许字段清单及禁止字段。

## 采集与留存方式

我们优先申请平台认可的官方 API、数据接口或授权导出。如果平台仅考虑网页方式，请明确授权的域名、路径、User-Agent、身份认证要求、频率/并发上限、分页方式及适用的 Robots 规则。若 Robots 禁止目标路径，只有在平台书面明确批准的具体访问方式和范围后才会评估；不会以 Robots 允许替代数据使用授权。

项目现有留存策略为：挂牌数据和价格历史随关联业务记录保留；压缩页面证据仅在获准且确有必要时留存，并随关联记录保留；数据库及页面证据备份保留 90 天。请确认该策略是否可接受，或给出最长留存期限、删除时限、删除请求处理及审计要求。若不允许保存完整 HTML，将改用平台批准的字段快照或其他证据形式。

## 展示与传播范围

请分别说明是否允许：

1. 仅在运营者内网后台查看及分析；
2. 经人工审核后，向购房者展示有限挂牌字段、来源名称和原始链接；
3. 基于同一挂牌生成价格变化提醒；
4. 在用户明确授权后，将用户需求提供给合作中介以协助联系或带看；
5. 上述用途是否允许免费提供，及任何商业化、广告、收费或第三方协作的附加条件。

未经明确批准，我们不会公开转载页面、图片或完整数据集，不会把挂牌价表述为成交价，也不会将同套候选自动认定为同一房屋。

## 请平台书面确认

1. 本申请适用的最新用户协议、数据规则和版本/生效日期；
2. 获准的数据来源、访问路径、获取渠道及地理范围；
3. 允许字段、请求频率、技术要求和授权期限；
4. 内部使用、免费展示、提醒和经用户授权撮合分别获准的范围；
5. 页面或字段证据的存储、备份、保留、删除及平台撤回授权后的处理要求；
6. 是否允许存储页面副本；如不允许，可接受的替代证据形式；
7. 必须展示的来源标注、链接、免责声明或其他告知；
8. 涉及个人信息时允许处理的字段、目的、保存期限和删除方式；
9. Robots 对目标路径的适用要求，以及平台认可的授权访问方式；
10. 申请、签约或接入官方 API/数据合作所需的后续流程与材料。

收到书面回复并完成内部范围核对前，本项目不会启动对应来源的在线请求，也不会把公开可访问、Robots 允许或技术上可读取视作授权。
