# 管理后台 MVP

当前 PR A 提供服务端渲染的总览页和单操作者登录。使用现有 API，不新增业务数据模型。

## 本机启动

```sh
docker compose up -d --build
```

默认只绑定 `127.0.0.1:8787`。浏览器打开 <http://127.0.0.1:8787/admin/>，使用部署环境中的 `APP_API_KEY` 登录。若通过 NAS 访问，应保持端口仅绑定 NAS 回环地址并使用 SSH 隧道；如需可信内网直接访问，只能绑定 NAS 的私有 LAN 地址并由防火墙限制网段，不得设置公网监听或端口转发。可信内网直接访问时使用 NAS 私有 LAN 地址并配置防火墙白名单；该后台拒绝转发客户端身份的代理头，因此不要通过会添加 `Forwarded`、`X-Forwarded-For` 或 `X-Real-IP` 的反向代理访问。远程运维使用 SSH 隧道。

页面不在 JavaScript 或浏览器配置中保存 API Key。登录成功后，服务端设置 8 小时有效的签名、HttpOnly、SameSite Strict Cookie；修改操作需带 CSRF token。没有数据库记录时显示空状态，不生成模拟房源。

## 页面状态

- 首页统计来自正式挂牌、待审核候选和近 7 天新增记录。
- 来源、账号与视频显示数据库中的最新状态。未配置 DTK 时明确显示“尚未配置 DTK 服务”。
- 首页用价格历史聚合统计30天同来源挂牌降价，不运行完整机会扫描；机会详情按需读取现有服务，低于挂牌中位数和跨平台线索覆盖最近90天，最多扫描1200套。

本页面是 NAS 内部单操作者工具，不是公开多用户服务。在线网站采集是否可用仍由现有来源策略控制。


## 房源与审核页面（PR B）

- 房源列表支持区域、小区、面积区间、价格区间和最少卧室筛选；详情展示挂牌来源、当前状态和按时间排序的价格证据。
- 候选页展示解析字段、字段证据、警告、原始快照 SHA-256 与来源链接；保存的HTML由受登录保护的页面按哈希读取、核对 SHA-256 后转义为文本显示；哈希不符或文件损坏时拒绝展示。纠错字段需逐项勾选；勾选后留空表示明确清空，未勾选字段不会覆盖证据或写入人工来源。通过/拒绝复用现有 collection service，并带服务端 CSRF 校验。
- HTML 导入限制在 1MB 快照，只创建待审核候选；正式挂牌与价格历史只会在人工审批后写入。
- 后台页面服务端渲染，所有页面路由从 OpenAPI schema 隐藏，来源 URL 只允许 HTTP(S) 链接。


## 条件找房与监控（PR C）

- 条件单编辑使用现有保存条件模型与匹配服务，页面展示总匹配量和逐条理由。
- 机会页允许切换7/30/90天，分开展示同来源挂牌实际降价与待核实的可比/跨平台线索，并提供价格证据来源。
- 账号页展示每个账号的最新运行记录、成功时间、已导入视频与提取字段；微信视频号标记手工导入，DTK缺失时明确标记尚未配置。

## 统一视觉系统（UI PR1，ZCode）

- 设计令牌：画布 `#F6F8FA`、深海蓝侧栏/主字 `#14263A`、深青强调/主按钮 `#147D79`、暖金提示 `#C48A36`；卡片 12px 圆角、克制阴影、表格行悬停、状态药丸、虚线空状态；中文系统字体栈，等宽数字。
- 结构：`app/static/admin.css`（唯一同源样式表）+ `app/admin_layout.py`（侧栏导航/顶栏/页壳/安全头/静态白名单）。静态资源由 admin 路由 `/admin/static/{name}` 提供（固定文件名白名单 + 私网校验 + 300s 缓存），`app/main.py` 未改动。
- CSP：默认 `script-src 'none'`；仅加载同源 UI 脚本的页面放宽为 `'self'`（无内联脚本、无 CDN）。登录页保持无脚本。
- 导航：总览 / 房源库 / 候选审核 / 视频素材 / HTML样本导入 / 条件找房 / 降价机会 / 视频监控；≤900px 折叠为顶部横向滚动导航。登录、CSRF、价格证据与全部文案语义未变。

## 视频素材页（UI PR2，ZCode；对接 Issue #30 后端合同）

- `/admin/videos`：上传入口 + 任务列表（状态药丸：queued/processing/completed/failed/failed_unavailable_ocr）。
- `/admin/videos/upload`：拖拽/点选上传，浏览器端预检扩展名与大小，XHR 进度条；`来源类型` 与 `来源与授权说明（≥10字）` 必填；提交经会话+CSRF 由服务端转发到 Issue #30 后端（`MEDIA_UPLOAD_API_BASE`，默认 `http://127.0.0.1:8788`），APP_API_KEY 不出服务端进程。
- `/admin/videos/{id}`：状态自动刷新（3s，终态停止）、失败原因与安全重试、逐帧 OCR 文本（帧号/时间点/置信度）、待核实线索（价格/面积/户型/小区 + not_calibrated + 既有警示文案）、字段证据 quote/来源/偏移。
- 后端未接入时页面显示明确的"未接入/待部署"状态并停用表单，不展示虚构识别结果。上传链路依赖 `python-multipart`（已加入 requirements.txt）。
