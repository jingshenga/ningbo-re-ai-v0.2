## 3. 证据链抽检（第二轮）

- `hints.evidence` 逐条含 `field/value/source/quote/start_char/end_char`：`'四室'`、`'365万'`、`'160m²'`、`'东湖花园'`，source 均为 `ocr_text`，偏移与原文一致。
- OCR items 逐条含 `frame_index / timestamp_seconds / confidence / frame_path`（帧文件路径，随 `--keep-work` 保留可复核；默认临时目录清理后路径仍作来源记录）。
- multi-price 四类价格（历史价/现价/成交价/首付）全部仅进 `price_mentions_wan`（`not_calibrated`，`method=rule_based_hints_not_verified`），warnings 保留"不得自动当作正式挂牌价"。

## 4. 遗留场景与建议

1. **【中】blur-compress 面积单位退化**：`㎡` 识别为裸 `m`，`AREA_RE` 不收裸 `m` → 面积丢失（价格/小区/户型不受影响）。建议：把"标签后跟 数字+m"纳入低置信候选并标记待审——需产品确认后另行小 PR，不建议静默放行。
2. **【低】`㎡`→`m²` 稳定等价变体**：extractor 已兼容，无需处理。
3. 竖屏缩帧已入库（PR A）：帧装入 1280×720 盒、保比例、偶数对齐；极小源上采样至高 720 可接受（清晰度有利且内存有界）。

## 5. 真实视频验收（未开始，阻塞于授权素材）

目标：≥10 段**确认有权处理**的真实房产介绍视频（横竖屏、清晰度、字幕风格多样）。标注规范与 CSV 模板见 `docs/VIDEO_ANNOTATION_GUIDE.md`；零代码接入：同结构标注 + `scripts/quality_pilot_*.py` 复跑。素材到位前不宣称任何真实识别准确率；不自动抓取抖音/视频号。
