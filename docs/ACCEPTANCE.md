## 3. 在线采集安全验收（默认模式）

1. `.env` 为 `ENABLE_ONLINE_COLLECTION=false`，`source_registry` 均`online_enabled=false`。
2. 即使登记 `enabled=true` 的采集目标，worker只记录 `blocked_policy`，不访问目标网页。
3. 即使运营者审核通过，机器总开关没有打开时仍阻断。
4. 目标robots禁止、不可用、HTTP403/429、重定向，或HTTP 200响应中含验证码/反爬挑战标记时，不重试、不切换代理，记录`blocked_robots`或`blocked_upstream`。
5. 非指定域名、HTTP、带用户密码或非443端口均拒绝。
- 2026-11-10模拟HTTP 200的58反爬与中文验证码响应均被`blocked_upstream`阻断、未重试、正文未进入错误信息；NAS Worker-only部署后源码哈希匹配、容器内检测通过。NAS来源在线OFF、启用目标0；未访问房源页。
- 2026-11-10条件单筛选迁移005在生产备份后执行；部署前saved_searches=0，迁移后4列和约束存在、行数仍0。API/Worker重建后认证GET `/api/saved-searches`=200且0条，DB healthy、`/healthz`=200；来源OFF、启用目标0。新字段持久化/提醒行为已由此前NAS隔离PostgreSQL集成用例8项验证，本轮未写生产测试数据。

## 4. 真实页面解析指标（P0目标，非已达成）
- 每平台≥20份合法使用来源的人工标注页面，正例和负例共存；清单格式与检查方法见`docs/SAMPLE_DATASET.md`和`scripts/validate_sample_set.py`。
- 页面标题、小区、总价、面积等九项字段每项**抽取精确率目标≥95%（在已抽取字段上）**，文本字段比较前做Unicode NFC与空白折叠，数值字段按Decimal比较；覆盖率另报，不用省略失败样本提高精确率。标题须有人工标签；缺失时按`missing_fields`记录；解析器对标注缺失字段的非空输出按误报计入准确率/精确率，不能改善指标。`oral_prices`/`transaction_prices`标记且挂牌价为空时也计作明确缺失挂牌价；非挂牌金额误报计入字段准确率/精确率及专门场景指标。未解析的`multiple_prices`仍单独评估，不纳入单值挂牌价指标。`evaluate_parser.py`报告每字段`precision_pct`及`precision_target_met`；每站20份样本量是否达到仍单独显示，不因小样本的高精确率而自动通过样本量门槛。`sample_composition`同时列出各来源挂牌状态及必需/歧义场景样本数，便于审阅评估集构成。 对使来源ID、小区、面积或挂牌价等核心必需字段缺失/歧义的样本，评估场景还须确认`ready_for_review=false`；仅可选字段歧义仍按字段留空、警告及候选证据检查。
- 区分采集成功、解析成功、字段完整、人工审核通过四个比率。
- 比率按来源累计统计：采集成功率=`success/(success+failed)`，blocked排除；解析成功率=`parse_success/parse_attempt`，仅成功获取并进入解析器的页面计为尝试；字段完整率=`四字段完整的解析成功结果/解析成功结果`，四字段为来源挂牌ID、小区、总价、面积；人工审核通过率=`approved/(approved+rejected)`，pending排除。百分比保留两位小数，分母为0返回null。解析告警/缺字段本身不代表解析失败。
- 同源ID稳定性复核；禁止用字符串相似代替ID。
- 采集阻断要可见，不能把空数据错误解释为“无房源”。
